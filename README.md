# CKS Accounts

React 18 + TypeScript + Vite + Ant Design 5 accounting dashboard for CKS Documents & Xerox.

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

## Included
- Professional navy, blue and teal finance-dashboard theme
- English / Tamil language selector
- Daily income and expense entries
- Employee and monthly salary management
- Dashboard and business reports
- Excel export (Transactions, Employees, Salary sheets)
- Browser print / Save as PDF
- Demo data persisted in browser localStorage

All records are demo data. Add a backend, authentication and backups before production use.
